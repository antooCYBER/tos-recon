# TOS-Recon 🚀
Framework modulare in Bash per la ricognizione dei sottodomini e l'analisi dei WAF (Web Application Firewall).

## 📁 Struttura dei Tool
* **`recon.sh`**: Script per l'estrazione e la pulizia dei target/sottodomini.
* **`bypass.sh`**: Scanner basato su `curl` per verificare lo stato HTTP live dei target ed eventuali protezioni.

## ⚙️ Utilizzo rapido

1. **Clona la repository:**
   ```bash
   git clone [https://github.com/antooCYBER/tos-recon.git](https://github.com/antooCYBER/tos-recon.git)
   cd tos-recon
Assegna i permessi di esecuzione:

Bash
chmod +x *.sh
Esegui la ricognizione:

Bash
./recon.sh
Avvia il controllo dei WAF/Stato HTTP:

Bash
./bypass.sh
